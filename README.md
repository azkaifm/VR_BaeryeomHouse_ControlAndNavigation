# Baeryeom House: Control and Navigation in VR

## Deskripsi Proyek
Proyek ini merupakan bagian dari riset tesis pascasarjana yang berfokus pada evaluasi interaksi manusia dan komputer dalam lingkungan Virtual Reality (VR). Studi kasus yang digunakan adalah **Baeryeom House**, sebuah bangunan tradisional Korea (Hanok), untuk membandingkan efektivitas berbagai metode kontrol dan navigasi.

## Fokus Riset
Eksperimen ini membandingkan dua modalitas interaksi utama:
* **Motion Controller:** Menggunakan perangkat kendali standar VR.
* **Hand Tracking:** Interaksi alami menggunakan tangan tanpa kontroler fisik.

Serta mengevaluasi metode navigasi:
* Teleportation
* Joystick Movement
* Real-world Walking (Physical Navigation)

## Spesifikasi Teknis
* **Unity Version:** 2022.3.6f1
* **XR Plugin:** XR Interaction Toolkit & Meta XR SDK
* **Target Device:** Meta Quest 2 / Quest 3
* **Aset 3D:** Realistic Hanok Environment (High-fidelity textures)

## Folder Utama
* `Assets/`: Berisi semua prefab, script, dan scene eksperimen.
* `Packages/`: Dependensi library Unity yang digunakan.
* `ProjectSettings/`: Konfigurasi proyek Unity.

## Cara Menjalankan Proyek
1. Clone repositori ini: `git clone https://github.com/arvrugm/BaeryeomHouse_ControlAndNavigation.git`
2. Pastikan Anda telah menginstal **Git LFS** untuk mengunduh aset besar (Terrain & Textures).
3. Buka folder menggunakan Unity Hub (Versi 2022.3.6f1).
4. Buka scene utama di folder `Assets/Scenes/`.
